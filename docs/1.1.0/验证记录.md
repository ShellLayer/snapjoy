# 拾光相机 1.1.0 验证记录

验证日期：2026-11-06。环境：Windows x64。发布版本：1.1.0。

## 功能与回归

`npm test` 的 9 项端到端测试全部通过，测试使用模拟摄像头、公开测试图片和临时相册。

1. 48 种效果（含原片）对同一输入产生不同输出；镜像、PNG 拍摄、相册和设置持久化正常。
2. 四连拍、取消、防重复拍摄、删除和另存为保持正常。
3. 摄像头权限拒绝、重试、设备缺失和运行中断连均有正确状态。
4. 保存失败保留待保存照片，修复后可重试；非法保存请求被拒绝。
5. 无 WebGL 时可以拍照，并把贴纸保存到照片。
6. 96 款贴纸和 12 款相框均绘制非空且互不相同；搜索和分类有效。
7. 贴纸拖动、大小、旋转、撤销与重启保留有效。冻结同一输入后，保存的 PNG 与预期合成画面逐字节一致；编辑选框不写入照片。
8. 本地后台线程成功加载随程序打包的人脸定位模型，能在公开测试图片上定位人脸；镜像前后的定位正确对应。
9. 四连拍每一格均包含相框和贴纸；随机造型及 980 × 720 小窗口的编辑操作正常。
