# 拾光相机 1.0.0 验证记录

验证日期：2026-11-06。环境：Windows x64。

## 功能检查

使用 Playwright 启动 Electron，接入 Chromium 模拟摄像头，在独立临时目录中保存测试照片。5 项端到端测试全部通过：

1. 默认不开启摄像头；开启后不采集声音。18 种效果对同一输入产生不同像素输出，镜像与预期翻转一致。保存的黑白 PNG 有实际明暗变化，尺寸为 4:3；重启后相册与设置保留。
2. 四连拍生成包含四个不同时刻画面的纵向照片条。倒计时可取消，连续触发拍照不会重复保存，删除前有确认，原图移到回收站。
3. 权限拒绝时显示恢复提示，重试后可拍摄；最小窗口尺寸 980 × 720 下主要控件可见。
4. 模拟保存位置不可写时保留待保存照片，修复后重试成功。不合规的照片与文件编号被拒绝；另存后的内容与原图完全一致。
5. 无 WebGL 时自动使用兼容模式并可拍照。未发现摄像头与运行中断连均有提示，禁止继续使用失效画面拍照；空格快捷键可从特效按钮触发拍照。

## 打包检查

- Windows 文件夹版本：实际启动，确认运行的是打包应用，18 种效果界面正常，摄像头默认关闭；使用模拟摄像头连接到 1920 × 1080 视频，音频轨为 0，可正常关闭相机。
- Windows 单文件免安装版：实际解压启动，确认本地界面与桥接功能可用，摄像头默认关闭，开启按钮可用。
- 可执行文件的产品名称和版本已写入。
- 生产依赖审计：未报告漏洞。此项不等于对操作系统或全部开发工具链的安全认证。

程序与测试均未拍摄用户的真实摄像头画面。真实设备的画质、驱动、权限及性能仍需在首次使用时确认。
