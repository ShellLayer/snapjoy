合计 32 项通过、1 项按平台跳过。测试覆盖 48 种效果的不同输出、96 款贴纸与 12 款相框、镜像、PNG 与取景合成一致、四连拍、编辑与撤销、照片与设置持久化、错误恢复、本地人脸定位和镜像关键点。新增的模型失败恢复测试会模拟首次初始化失败，确认仍可手动拍照，关闭并重开摄像头后恢复模型加载。

Mac 专属测试覆盖原生菜单、隐私设置入口、摄像头授权的受控状态，以及关闭窗口后从 Dock 重新打开。Intel 测试明确指定 x64 Electron，并在运行时核对 `process.arch`，防止兼容环境自动切换到 arm64。

## 打包后的程序

- 三种程序均实际启动，确认版本为 1.2.0、标题为“拾光相机 · SnapJoy”，48 种效果、96 款贴纸和 12 款相框完整。
- 默认摄像头关闭。使用模拟摄像头连接后，视频为 1920 × 1080、音频轨为 0，本地人脸定位模型加载正常。
- Mac 两个应用均通过 `codesign --verify --deep --strict`；读取 Info.plist 确认摄像头用途说明和最低系统版本 macOS 13.0；检查 Mach-O 架构分别为 arm64 与 x86_64。
- Mac 使用 ad-hoc 临时签名，没有 Apple Developer ID 签名与公证。
- Windows 另实际启动单文件免安装包，确认可以解压运行、摄像头默认关闭。

本目录保留每个平台的 `package-verification-*`、`bundle-verification-*` 和 `graphics-*` JSON，以及 Windows 单文件验证结果。`Mac界面.png` 来自 Mac 自动测试中的欢迎界面。

## 范围与安装

测试使用模拟摄像头、MediaPipe 公开测试图片和临时相册，没有访问用户真实摄像头。Intel 图形验证通过 Rosetta 完成，尚未在物理 Intel Mac 的摄像头与显卡上实拍验证；实际摄像头驱动、光线和儿童面部跟随表现仍需实机确认。

Mac 下载包分别提供 Apple 芯片和 Intel 的 DMG、ZIP。打开 DMG 后拖入「应用程序」。首次打开的系统提示和摄像头权限步骤见 [发布说明](../releases/1.2.0.md)。

`SHA256SUMS.txt` 对应 GitHub 发布页中的五个二进制下载文件，可用于核对安装包。
