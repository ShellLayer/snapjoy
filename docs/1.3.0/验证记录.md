## 完整基线的功能验证

| 程序与运行环境 | 结果 |
| --- | --- |
| Mac arm64，Apple 芯片原生运行 | 18 项通过 |
| Mac x64，在 Apple 芯片上经 Rosetta 运行 | 18 项通过 |
| Windows x64 原生运行 | 17 项通过；1 项 Mac 专属测试跳过 |

测试覆盖以下行为：

- 60 种效果、120 款矢量配饰、24 款相框的不同绘制输出；搜索、分类与 24 套造型入口。
- 5 种画幅保存后的真实像素尺寸，以及 WebGL 与兼容渲染器使用同一中心裁切；大取景模式扩大画面。
- 各跟随位置在不同画幅中的移动、旋转、偏移、命中选择和设置持久化；兼容旧造型。
- 模拟人脸图片的本地定位、镜像关键点、模型加载失败后恢复；贴纸拖动、缩放、旋转、撤销和合成 PNG 的逐字节一致性。
- 单张、四连拍、防重复拍摄、取消、删除、导出、权限拒绝、摄像头断开和保存失败重试。
- 带相框的真实 MP4 录像、暂停与继续、时长排除暂停、回放、进度定位、导出字节一致和删除；1920 × 1080 视频可解码。
- 声音默认关闭；主动勾选后录入音轨，停止后释放；麦克风拒绝时可继续录制无声视频。
- 非法录像写入拒绝；索引保存失败后重试；模拟写入 32 字节后中断，重试时先回退到上次成功位置，防止视频头重复或丢失。
- Mac 原生菜单、摄像头与麦克风设置入口、Dock 重新建窗，以及废弃录像会话不阻塞新窗口。

本次 Mac 回放检查发现，本地文件代理虽然可以解码 MP4，却没有提供有效的可定位范围。改为显式返回字节范围、长度和媒体类型后，原生 Mac 回放检查已通过。测试同时核对首段、末段和无效范围请求，并在打包后的应用中再次实际拖动播放位置。

## 最终录像尺寸回归

录像采用的 H.264 编码设置可以处理 1920 × 1080，但不保证能处理 1920 × 1920。最终实现同时限制录像长边与总像素，4K 摄像头画面按画幅适配；照片仍可保留更高原生尺寸。新测试实际编码并解码以下五种尺寸，而不只检查数学计算：

| 画幅 | 高分辨率输入下的视频尺寸 |
| --- | --- |
| 16:9 | 1920 × 1080 |
| 4:3 | 1662 × 1246 |
| 1:1 | 1440 × 1440 |
| 3:4 | 1246 × 1662 |
| 9:16 | 1080 × 1920 |

五种尺寸均已在 Windows、Apple 芯片 Mac 和 Mac Rosetta 的 x64 程序中完成真实编码与解码。Windows、Apple 芯片的最终 8 项回归全部通过；Intel 对应 8 项通过上述两轮完成覆盖。三平台安装包中的短视频回放与进度定位也全部通过。

部分构建机的编码、解码、启动与保存较慢。测试维护将固定等待改为等待真实编码数据、解码帧和音轨就绪，录制时长从用户实际停止点击计量，并延长 Rosetta CI 的启动及断言等待；颜色、尺寸、播放位置、音轨数量、导出一致性及原先 0.2 秒的计时误差要求均保留。这些修改不改变发布程序。对于尚未生成任何视频画面的短录像，程序会明确提示重录，不把空文件加入相册。

## 打包与安装

- Windows 安装版在干净的 CI 临时目录实际安装并启动，检查版本、60 种效果、摄像头默认关闭和录像入口；免安装版另行解压启动验证。
- 所有发布程序均需实际启动，核对架构、版本、隔离设置、5 种画幅、120 款配饰、24 款相框和本地人脸模型加载。
- 打包后的程序在临时 CI 相册录制短视频，并检查真实文件回放和播放进度定位。
- Mac 读取 Info.plist 核对摄像头／麦克风用途说明、最低系统版本 13.0 和目标架构，并执行严格的签名完整性检查。
- 本地 Windows 文件夹版也已重新打包、启动验证；`local-package-verification-win32-x64.json` 中 `recordedVideo: null` 表示本地检查没有向用户相册写入测试视频。

本目录的 `package-verification-*`、`bundle-verification-*`、`graphics-*`、`installer-verification.json`、`portable-verification.json` 保留实际检查结果。`Mac界面.png` 来自 Mac 测试的欢迎界面。

## 发布与覆盖范围

[v1.3.0 公开预览版](https://github.com/ShellLayer/snapjoy/releases/tag/v1.3.0)已发布，包含 Windows 安装版、便携版，Apple 芯片与 Intel Mac 的 DMG 和 ZIP，共 6 个程序包，另附 `SHA256SUMS.txt`。

逐项核对了发布标签的提交、全部文件名与大小、本地 SHA-256 和 GitHub 资产摘要；6 个程序包的公开链接均通过匿名 HTTP 检查，返回 200。公开的校验文件与本地内容逐字节相同。机器可读记录见 [release-verification.json](release-verification.json)，校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)。发布标签创建后自动触发的一轮重复构建已取消，避免重复覆盖已验证的发布文件。

自动验证使用模拟摄像头、模拟麦克风、MediaPipe 公开测试图片与临时相册，没有使用用户真实摄像头或录制用户声音。没有把短视频检查表述为连续十分钟实拍压力测试。真实摄像头驱动、光照、儿童面部跟随和长时间录制体验仍需实机确认。

完整基线与 Apple 芯片最终包在 macOS 26 验证；Intel 的 7 项复查使用 macOS 15 Rosetta，最后的保存重试及发布安装包使用 macOS 26 Rosetta。最低系统版本配置为 macOS 13，但不代表已覆盖各旧系统和物理 Intel Mac。Mac 使用 ad-hoc 临时签名，没有 Apple Developer ID 签名或公证；Windows 安装包没有发布者证书签名。首次启动步骤见[发布说明](../releases/1.3.0.md)。
