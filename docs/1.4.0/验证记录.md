# SnapJoy 1.4.0 发布验证

验证日期：2026-11-07（北京时间）。版本源码：`430d8f206be53720c21b251e27f240d4bed09c56`。构建任务：[Build desktop packages](https://github.com/ShellLayer/snapjoy/actions/runs/42298182788)。测试、安装包和版本标签均以该提交为依据。

本轮将已完成的本地增强版升级为 1.4.0，保留其 84 种效果、152 款脸部装饰（含 32 款面具）、24 款相框和 40 套造型。发布配置按项目版本归档安装包与检查记录；为较慢的 Mac 兼容运行环境增加启动等待时间，打包录像检查等待真实编码数据后才停止。

## 打包检查范围

三平台分别生成并启动发布程序，检查实际版本、架构、素材数和本地人脸模型。云端临时相册额外检查打包程序的短视频录制、回放与进度定位；Windows 另外安装 NSIS 安装包并启动，便携版单独解压运行；Mac 核查应用架构、摄像头／麦克风用途声明、最低系统版本和签名完整性。

本地 Windows 文件夹版亦已重新打包并实际启动，根目录快捷方式指向 `release/1.4.0/win-unpacked/拾光相机.exe`。`local-package-verification-win32-x64.json` 保留本地检查记录；其中 `recordedVideo: null` 表示没有向用户的真实相册写入测试视频。

本目录的 `graphics-*`、`bundle-verification-*`、`package-verification-*`、`installer-verification.json` 和 `portable-verification.json` 保存各平台的实际检查记录。

## 验证边界

检查使用模拟摄像头、模拟麦克风、项目原有公开测试图片和临时相册，没有录制用户画面或声音。短片测试不代表十分钟连续实拍压力测试。Mac 最低系统版本配置为 13.0；本次构建使用 macOS 26，Intel x86_64 程序在 Apple 芯片上经 Rosetta 运行，不等同于覆盖所有旧版系统、真实摄像头和物理 Intel Mac。

面具属于二维装饰，不模拟张嘴与三维转头。Mac 为 ad-hoc 临时签名，未接入 Apple Developer ID 与公证；Windows 安装包没有发布者证书。首次启动方法见 [1.4.0 发布说明](../releases/1.4.0.md)。
