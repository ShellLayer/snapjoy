SnapJoy 1.4.0 将本地面具增强版带到 Windows 和 Mac，新增的装扮都能用于拍照和录制视频。

### 本次更新

- **84 种特效**：新增 24 种，包括彩纸、飘雪、泡泡、萤火虫、樱花等动态效果，水墨、蓝晒、彩铅、丝网、拼豆和毛线画风，以及玻璃水球、波纹隧道、扇形分身、百叶魔镜等搞怪效果。
- **32 款原创面具**：16 款动物面具和 16 款奇幻角色面具，包括狐狸、熊猫、小龙、机器人、精灵、独角兽、凤凰等；与原有配饰合计 **152 款装饰**。
- **眼部镂空与自动贴脸**：面具依据双眼位置、眼距和倾斜角度跟随；可手动调整位置、大小和角度。换款会替换上一张面具、保留其他配饰，支持撤销。
- **40 套一键造型**：新增猫咪茶话会、赤狐森林、银河机器人、珊瑚泡泡、彩蝶舞会等 16 套搭配，保留 24 款主题相框。
- 保留大取景、5 种画幅与照片尺寸调整，以及视频暂停／继续、可选声音、回放、进度拖动和导出。没有 WebGL 时可使用 27 种基础效果，全部面具和配饰仍可使用。

打开软件后，在「**贴纸·面具 → 面具**」选择新角色，也可以使用「一键造型」快速搭配。

### 下载与安装

| 电脑 | 文件 |
| --- | --- |
| Windows 10/11，64 位，推荐安装版 | `SnapJoy-1.4.0-Windows-Setup.exe` |
| Windows 64 位，免安装版 | `SnapJoy-1.4.0-Windows.exe` |
| Mac，Apple 芯片（M 系列），macOS 13+ | `SnapJoy-1.4.0-macOS-arm64.dmg` |
| Mac，Intel，macOS 13+ | `SnapJoy-1.4.0-macOS-x64.dmg` |

Windows 安装版按向导安装；Mac 打开 DMG 后将「拾光相机」拖进「应用程序」。ZIP 为对应 Mac 版的备用压缩包；`SHA256SUMS.txt` 用于校验下载完整性。升级前退出旧版，新版沿用 **图片 / 拾光相机** 相册和原有设置，旧版本仍可从 Releases 下载。

Mac 应用采用临时签名，尚未完成 Apple Developer ID 签名与公证。首次启动如果被系统拦截，请参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在「系统设置 → 隐私与安全性」中为本应用选择「仍要打开」。Windows 安装包尚未进行发布者代码签名，首次下载可能显示发布者提示。

### 使用范围

所有素材、画面和作品在本机处理，没有账号或上传功能。摄像头与麦克风分别授权；只有主动勾选「录制声音」才申请麦克风权限。

面具属于二维装扮，眼部透明，嘴部图案不会随张嘴变化；默认跟随主要一张脸，侧脸、遮挡或强烈变形下可手动微调。自动检查使用模拟摄像头、模拟麦克风和公开测试图片；Apple 芯片使用原生 Mac 环境，Intel x86_64 程序通过 Rosetta 检查，不等同于覆盖所有真实摄像头、儿童脸型、旧版 macOS 和物理 Intel Mac。
