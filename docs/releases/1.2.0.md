SnapJoy 新增 macOS 下载版，原有 48 种效果、96 款贴纸、12 款相框、四连拍和本地相册均可使用。

### 选择下载

- **Mac（Apple 芯片）**：`SnapJoy-1.2.0-macOS-arm64.dmg`，适用于 M 系列芯片。
- **Mac（Intel）**：`SnapJoy-1.2.0-macOS-x64.dmg`。
- **Windows 64 位**：`SnapJoy-1.2.0-Windows.exe`，免安装运行。
- ZIP 是对应 Mac 应用的备用压缩包；`SHA256SUMS.txt` 可用于核对下载文件。

Mac 版要求 macOS 13 Ventura 或更新版本。可在苹果菜单 → 关于本机查看芯片和系统版本。

### Mac 安装与摄像头

1. 打开对应的 DMG，将「拾光相机」拖到「应用程序」。
2. 从「应用程序」打开，点击「开启摄像头」时允许摄像头访问。
3. 照片保存在用户的「图片 / 拾光相机」文件夹，软件内可直接打开。
4. 若拒绝过权限，在系统设置 → 隐私与安全性 → 摄像头中启用「拾光相机」，再退出并重新打开软件。

此版为 **Mac 预览版**：使用临时签名，尚未取得 Apple Developer ID 签名及公证。首次打开可能被 macOS 提示无法验证开发者。若确认下载来自本仓库，可参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在系统设置 → 隐私与安全性中为本应用选择「仍要打开」。本项目不要求关闭系统整体安全检查。

构建流程会在 Apple 芯片 Mac 原生环境、Mac Rosetta 的 Intel 运行环境和 Windows 环境中使用模拟摄像头运行自动测试，并实际启动打包后的程序。Intel 包为 x86_64 原生程序，但本轮图形测试通过 Rosetta 完成，尚未在真实 Intel Mac 的摄像头与显卡上实拍验证。自动测试不等于对所有真实摄像头和儿童面部跟随效果的实拍验证。
