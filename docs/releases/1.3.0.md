SnapJoy 1.3.0 更新了取景界面和脸部装扮库，并加入视频录制。Windows 和 Mac 均可使用。

### 本次更新

- 更大的取景区，按 **F** 或「大取景」收起素材与胶卷条。
- **5 种画幅**：16:9、4:3、1:1、3:4、9:16；可选原生尺寸或长边 640 / 1280 / 1920 / 3840。实际大小受摄像头原生分辨率限制，界面会显示保存尺寸。
- **120 款原创脸部配饰**，其中新增 96 款：动物耳朵、职业帽子、眼镜、脸颊彩绘、魔法头饰、胡子、项链、围巾等。普通表情符号退出主列表，旧造型继续兼容。
- 每件配饰可选择**头顶、额头、眼睛、鼻子、嘴、脸颊、下巴、整脸、脖子**等跟随位置，并微调上下、左右、大小和旋转。
- **60 种效果、24 款相框、24 套一键造型**，可继续自由搭配。
- **视频录制**：保留特效、贴纸与相框；暂停／继续；声音默认关闭，勾选后才申请麦克风权限。空格或拍摄按钮停止并保存，最长 10 分钟，最高长边 1920，总像素不超过 1920 × 1080；例如方形最高 1440 × 1440，界面显示实际尺寸。隐藏窗口会暂停录像。
- 相册支持视频播放、进度拖动、另存为和移到回收站。按实际编码能力保存 MP4，必要时回退为 WebM。
- Windows 新增可选择安装位置的安装向导，同时保留便携版。

### 下载与安装

| 电脑 | 文件 |
| --- | --- |
| Windows 10/11，64 位，推荐安装版 | `SnapJoy-1.3.0-Windows-Setup.exe` |
| Windows 64 位，免安装版 | `SnapJoy-1.3.0-Windows.exe` |
| Mac，Apple 芯片（M 系列），macOS 13+ | `SnapJoy-1.3.0-macOS-arm64.dmg` |
| Mac，Intel，macOS 13+ | `SnapJoy-1.3.0-macOS-x64.dmg` |

Windows 安装版按向导安装；Mac 打开 DMG 后将「拾光相机」拖进「应用程序」。Mac ZIP 为备用压缩包。`SHA256SUMS.txt` 用于核对下载完整性。

相册沿用 **图片 / 拾光相机**，升级不更换相册目录。所有画面和作品在本机处理；没有账号与上传功能。首次使用配饰跟随时需要等待随程序附带的本地模型就绪。

Mac 应用采用临时签名，尚未完成 Apple Developer ID 签名与公证。首次启动如果被系统拦截，请参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在「系统设置 → 隐私与安全性」中为本应用选择「仍要打开」。Windows 安装包尚未进行发布者代码签名，首次下载可能显示发布者提示。

### 权限与使用范围

摄像头和麦克风分别授权。Mac 如曾拒绝权限，请在「系统设置 → 隐私与安全性 → 摄像头／麦克风」中为「拾光相机」开启，再退出并重新打开。软件帮助中有对应设置入口。录像声音没有开启时，不请求或使用麦克风。

自动跟随面向画面中的主要一张脸，左右以取景画面为准；侧脸、遮挡和强烈变形时可手动调整。自动测试使用模拟摄像头和麦克风，不等同于对所有真实设备和儿童面部跟随的实拍验证。Apple 芯片在 Mac 原生环境测试，Intel x86_64 程序通过 Mac Rosetta 验证；真实 Intel Mac 摄像头与显卡仍需实机体验。
